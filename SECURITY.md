# Security Policy

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

You should get an acknowledgement within five business days. Please give us a reasonable chance to fix the issue before disclosing it publicly.

## Scope

In scope:

- The code in this repository.
- The hosted service at `open.wenmarpro.com`, once it is live.

Out of scope:

- The Wenmar Pro application at `app.wenmarpro.com`. Report those through [wenmarpro.com](https://wenmarpro.com).
- Incorrect vehicle data. That is a data-quality issue; please open a wrong decode issue.
- Volume-based denial of service against the hosted service.

## Supported versions

The project is pre-release. Once releases exist, only the latest release receives security fixes.
